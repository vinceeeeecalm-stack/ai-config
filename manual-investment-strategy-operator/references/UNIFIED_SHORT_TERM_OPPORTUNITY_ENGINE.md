# 统一短期机会引擎 V1

本参考定义分钟级至最长 7 天的单一短期机会区。它不拆成日内和多日两套用户策略；系统自行选择预计持有时间，全部结果进入同一个战术资金池，持有时长只作为退出时钟和利润归因标签。

## 权威链路

`动态候选池 → 市场环境/事件 → 全候选现货与衍生品因子 → 持续候选和排名加速度 → 价值/催化/风险/流动性硬门 → 时间与信息衰减后的排名 → 时间匹配回归 → 唯一 research_top1 → 实时重确认 → ENTER_NOW / WAIT_FOR_ENTRY / NO_TRADE → 生命周期 → 资金加权净 ROI 与漏检复盘`

全轮价格、因子、排名和决策必须共享 `snapshot_id / strategy_version / config_digest / source_digest`。任一绑定变化即令旧决策失效。

## 七个合同

- `UnifiedShortTermOpportunityV1`：候选、预计持有时间、费用后保守利润、回撤、概率、催化及硬门。
- `ShortTermFactorSnapshotV1`：同一时点的现货、结构、衍生品、催化、流动性与数据质量。
- `NearMissCandidateStateV1`：第 4–20 名的追加式记忆、排名速度与动量加速度。
- `ShortTermDecisionV1`：唯一研究 Top1；正式动作只允许三种。
- `ShortTermLifecycleV1`：复核频率、计划失效、目标、止损和最迟退出，绝不超过 7 天。
- `MissedOpportunityReviewV1`：漏检分类和真实后续路径，只追加且不进入 ROI。
- `ShortTermProfitAttributionV1`：同一策略版本、同一个真钱战术资金池的资金加权净 ROI；Paper 必须拒绝。

## OI 与提前识别

OI 只代表新增仓位和潜在燃料，不能单独证明方向。至少还要同时看到现货主动买盘、价格结构、合约主动成交、不过热资金费率与可退出流动性。`EARLY_WARNING` 是内部持续候选状态，不是用户交易动作。

## 排名与持有时间

先执行价值、催化、实时、回归、流动性和风险硬门，再比较费用/滑点/信息衰减后的保守净利润、单位时间单位风险利润、目标先于止损的保守概率、盈亏比、催化时间确定性与退出能力。质量相近时偏向更快兑现；更长持有必须以更高净优势补偿隔夜、信息衰减和监控负担。

## 分阶段晋升

阶段 0 只冻结和测量现有生产基线，不改变线上规则。随后每个阶段必须建立新的 superseding GoalContract，且每 14 天最多批准一个核心赚钱规则变化：衍生品前移、持续候选与排名加速度、自适应时钟、数据公平与局部降级、时间匹配回归、提醒/退出/漏检复盘。不得在同一窗口同时改变选标、入场、止损和退出。

阶段 0 的真实账本尚无到期结果时必须输出 `DATA_INSUFFICIENT`。确定性夹具仅验证实现与防前视，不是 Paper 或真钱证据，也不能提升 `BUSINESS_READY`。

## 风险边界

不自动下单；最长持有 7 天；短期亏损不得自动转长期；OI 单独上涨不得入场；旧行情或双源冲突不得入场；4–7 日机会没有持续催化和监控不得交易；战术池回撤 15% 暂停；没有合格机会时 `NO_TRADE` 是正确结果。
